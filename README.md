# 大肥鱼 QQ 人格档案

[大肥鱼-QQ人格卡.md](./大肥鱼-QQ人格卡.md) 是从现有 DSH 配置中整理的独立人格档案，归档版本为 2026-10-30。它保留原来那个可爱、软乎乎、懒散又有点傲娇的 QQ 大肥鱼，完整记录她的语言习惯、六维情绪、与“宝宝”的关系、群聊与私聊节奏，以及表情、记忆和日常互动设定；直播专属内容、过期活动和桌面操作配置已移除。

## 内容导航

- **01—06：人格设定**——身份、性格、喜好、语言、情绪与亲密关系。
- **07—14：QQ 行为及边界**——社交、主动聊天、等待与潜水、表情、记忆、作息、多媒体和隐私权限。
- **15：对话示例**——参考语气和节奏，不作为固定回复模板或真实经历。
- **16—17：依赖与来源**——可选工具、运行约束、来源依据及冲突处理记录。

## 使用方式

可用于备份、阅读、对照现有人格，或迁移到其他 LLM。迁移时以第 01—15 节作为人格与行为参考，依据目标环境核对第 16 节的工具依赖；第 17 节用于追溯来源，不作为角色台词。文档的 Markdown 是档案排版，QQ 发言仍遵循卡内的短句、自然分条风格。

这份文件不会自动接入 DSH，也不包含聊天记录或既有记忆库。导入人格不等于恢复历史记忆、启用工具或获得额外权限；语音、唱歌、日记和空间等行为，只有在相应能力真实可用且获准时才能执行。跨场景人格连续性始终服从隐私与可见范围。

## 已知限制

部分身份、白米饭偏好和旧示例来自历史角色备份，已与当前配置来源区分。北京话未找到明确原文依据，周末夜间作息存在重叠，原系统也仍有表情频率、唤醒推荐和发送协议方面的冲突；具体取舍见人格卡第 17 节。本档案用于保留原有人格，不代表这些运行问题已经修复。
